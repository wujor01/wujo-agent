Cách dùng

Cần một máy tính đã cài Claude Code và Node.js 20 trở lên. Mất khoảng hai phút.

  1. Cài WujoAgent trên máy tính

    Chạy lệnh sau trong terminal của máy đang dùng Claude Code.

    npm install -g https://agent.wujo.dev/download/wujoagent.tgz

  2. Chạy và quét mã QR

    Terminal hiện mã QR. Mở app, bấm Quét QR, hoặc dùng camera của điện thoại.

    wujoagent serve

  3. Chọn thư mục dự án và bắt đầu

    App liệt kê các dự án và session Claude Code đã có trên máy tính, kể cả session bạn mở từ VS Code hay terminal.

Làm được gì

Chat tiếp session cũ

Lịch sử được đọc từ chính máy tính, nên bạn tiếp tục đúng chỗ đang dở.

Duyệt từng thao tác

Claude hỏi trước khi sửa file hay chạy lệnh. Bạn cho phép, luôn cho phép, hoặc từ chối.

Xem thay đổi theo file

Nhánh, commit gần đây, từng dòng thêm và bớt. Fetch, pull, push ngay trong app.

Chọn model và chế độ

Đổi model cho từng session, chuyển giữa hỏi trước khi sửa, tự sửa file và lập kế hoạch.

Theo dõi mức sử dụng

Phần trăm ngữ cảnh, giới hạn 5 giờ và 7 ngày của tài khoản, kèm thời điểm đặt lại.

Lệnh gạch chéo

Gõ / để xem các lệnh và skill của dự án, giống như trên máy tính.

Bảo mật

WujoAgent không có máy chủ trung gian. Mã nguồn và nội dung chat của bạn không đi qua chúng tôi.

  • Kết nối trực tiếp. Điện thoại nói chuyện với máy tính của bạn, không qua dịch vụ nào của WujoAgent.
  • Cần token. Mỗi máy tính có một token riêng. Sai quá mười lần trong một phút thì địa chỉ đó bị chặn tạm.
  • Nên dùng Tailscale. Qua Tailscale, kết nối được mã hoá đầu cuối. Trong mạng Wi-Fi nội bộ, dữ liệu đi dạng HTTP thường, chỉ nên dùng ở mạng bạn tin.
  • Không mở ra internet. Ai có token thì điều khiển được Claude Code trên máy bạn. Đừng chia sẻ mã QR hay chuyển tiếp cổng ra ngoài.
