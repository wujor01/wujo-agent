Run Claude Code on your computer, from your phone

Reopen sessions you left unfinished, send new work, approve each action and review git changes. Your phone connects straight to your computer over your local network or Tailscale.

How it works

You need a computer with Claude Code installed and Node.js 20 or later. It takes about two minutes.

  1. Install WujoAgent on your computer

    Run this in a terminal on the machine where you use Claude Code. The package comes from the latest release on GitHub.

    npm install -g https://github.com/wujor01/wujo-agent/releases/latest/download/wujoagent.tgz

  2. Start it and scan the QR code

    The terminal shows a QR code. Open the app and tap Scan QR, or use your phone's camera.

    wujoagent serve

  3. Pick a project folder and start

    The app lists the projects and Claude Code sessions already on your computer, including ones you started in VS Code or a terminal.

What you can do

Continue existing sessions

History is read from your computer, so you pick up exactly where you stopped.

Approve each action

Claude asks before it edits a file or runs a command. Allow once, always allow, or deny.

Review changes by file

Branch, recent commits, every added and removed line. Fetch, pull and push from the app.

Choose model and mode

Switch model per session, and move between ask before edits, auto-accept edits, plan mode and auto.

Track usage

Context percentage, your account's 5-hour and 7-day limits, and when they reset.

Notified when done

Turn on notifications to know when Claude finishes or is waiting for your approval, even after leaving the app.

Slash commands

Type / to see your project's commands and skills, as on your computer.

Security

WujoAgent has no relay server. Your source code and chat content never pass through us.

  • Direct connection. Your phone talks to your own computer, not to any WujoAgent service.
  • Token required. Each computer has its own token. More than ten wrong attempts in a minute blocks that address for a while.
  • Tailscale recommended. Over Tailscale the connection is end-to-end encrypted. On local Wi-Fi the data travels as plain HTTP, so use it only on networks you trust.
  • Push notifications are optional. Off by default. When on, a notification shows only the project folder name, never chat content, and travels through the Expo and Apple or Google push services.
  • Keep it off the internet. Anyone with the token can drive Claude Code on your machine. Do not share the QR code or forward the port.
